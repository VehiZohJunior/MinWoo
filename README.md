# MinWoo

Plateforme d'apprentissage des langues Mandé-Sud : **Yacouba (Dan)**, **Toura**, **Gouro**.

## Objectifs

- Permettre à un maximum de personnes d'apprendre ces langues (étudiants, diaspora, grand public)
- Être une référence sérieuse pour les enseignants-chercheurs, chercheurs et laboratoires de recherche
- Faire grandir un corpus linguistique fiable au fil du temps, grâce aux contributions de locuteurs natifs et de chercheurs

## Approche

- **Format** : application web progressive (PWA) — accessible sans app store, utilisable hors-ligne, large portée
- **Apprentissage** : répétition espacée adaptée à chaque utilisateur
- **Corpus** : pipeline de contribution/validation par des locuteurs natifs et des chercheurs, avec des exports de données structurées compatibles avec les outils de linguistique de terrain (ELAN/FLEx, transcription IPA, codes ISO 639-3)

## Statut

Projet en phase de démarrage. Structure initiale du dépôt en place, contenu et code à venir.
